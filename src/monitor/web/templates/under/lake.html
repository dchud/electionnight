DuckLake: what this system stores, from its own catalog

DuckLake is a table format with its metadata in a SQL database. Here that database is one SQLite file, the data is Parquet files beside it, and DuckDB is the engine that reads both. Everything below comes from the catalog, except where a table's rows are read. See also Inventory for rows against keys in every table, Storage for files, snapshots, and time travel, and Data model for a table as the code declares it.
